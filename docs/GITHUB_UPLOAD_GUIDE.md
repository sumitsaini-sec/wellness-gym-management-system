# GitHub Upload Guide

## Repository

Recommended name: `wellness-gym-management-system`

Recommended description:

> Responsive gym management system with admin/member roles, attendance, membership billing, workout guidance, diet plans and an optional AI chatbot. Built with HTML, CSS, JavaScript, Node.js and Express.

## Suggested Topics

`gym-management-system`, `college-project`, `javascript`, `nodejs`, `expressjs`, `fitness`, `attendance-management`, `billing-system`, `chatbot`, `portfolio-project`

## Standard Git Commands

```bash
git init
git add .
git commit -m "Initial commit: Wellness Gym Management System"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/wellness-gym-management-system.git
git push -u origin main
```

## Do Not Commit

- `.env`
- API keys
- `node_modules/`
- `.venv/`
- `.vscode/`
- real passwords or tokens

## After Upload

Add a description, repository topics and screenshots. Pin the project on your GitHub profile if you want it highlighted in your portfolio.
