# Contributing

This project is primarily maintained as an academic/portfolio project, but improvements are welcome.

## Recommended Workflow

1. Create a new branch from `main`.
2. Keep each change focused on one feature or fix.
3. Test login, member management, attendance, billing, and chatbot behavior.
4. Do not commit `.env`, API keys, `node_modules`, `.venv`, or local editor settings.
5. Use clear commit messages such as:
   - `feat: add member search`
   - `fix: correct attendance counter`
   - `docs: improve setup guide`

## Pull Request Checklist

- [ ] No secrets are included.
- [ ] Existing pages still load correctly.
- [ ] JavaScript console has no new errors.
- [ ] Backend starts with `npm start`.
- [ ] Documentation is updated if behavior changed.
